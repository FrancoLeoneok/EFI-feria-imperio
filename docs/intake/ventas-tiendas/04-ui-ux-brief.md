# UI/UX — Ventas y datos de transferencia

## Referencias y estilo
Extender AdminPage, tarjetas del checkout y controles existentes. Conservar Plus Jakarta Sans, sand/charcoal, forest/terracotta, radios y variantes oscuras. Sin rediseñar la página.

## Componentes
Sección Ventas con cantidad de pedidos y tarjetas o detalle adaptable por pedido; cliente, fecha, productos, cantidades, subtotal y miniaturas de comprobantes que permitan ver la imagen completa. No mostrar productos ni comprobantes de otras tiendas.

Sección Datos de transferencia con alias/CVU y botón Cargar/editar CVU o alias. Formulario con etiquetas, ayuda y mensajes de validación. El alias inicial generado se identifica como De demostración hasta reemplazarlo por uno real mediante el formulario.

## Estados y accesibilidad
Carga, vacío, error con reintento y guardado exitoso. Foco visible, controles con nombre, teclado, textos largos sin desbordes y diseño móvil. No mostrar el total de todo un pedido como ingreso de una sola tienda.
